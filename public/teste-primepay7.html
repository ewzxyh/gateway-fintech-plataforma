🔧 Configuração

Para configurar a PrimePay7, acesse:

GET /admin/ajustes/adquirentes

Configure os seguintes campos:

🔑 Chaves de Autenticação:

  • Chave Privada: sk_... - Para operações sensíveis (saques)
  • Chave Pública: pk_... - Para operações públicas (depósitos)
  • Chave de Saque Externo: wk_... - Para transferências externas
💡 Importante: A PrimePay7 usa apenas as 3 chaves acima. NÃO é necessário Client ID ou Client Secret!

⚙️ Configurações Gerais:

  • URL: https://api.primepay7.com (produção) ou https://api-sandbox.primepay7.com (sandbox)
  • Sandbox: Ative para ambiente de teste
  • Status: Ative para usar a adquirente

💰 Cash-In (Depósitos)

A PrimePay7 suporta depósitos via PIX através de QR Code dinâmico:

Endpoint de Depósito:

POST /api/wallet/deposit/payment

Parâmetros:

{ "token": "seu_token", "secret": "seu_secret", "amount": 100.00, "debtor_name": "Nome do Cliente", "email": "redacted@example.invalid", "phone": "11999999999", "method_pay": "pix", "postback": "https://seu-site.com/webhook" }

Resposta:

{ "status": "success", "data": { "qr_code": "00020126360014BR.GOV.BCB.PIX...", "qr_code_text": "Texto do QR Code", "transaction_id": "uuid-da-transacao", "amount": 100.00, "expires_at": "2025-09-29T15:30:00Z", "pix_key": "chave-pix-da-conta" } }

💸 Cash-Out (Saques)

A PrimePay7 suporta saques via PIX:

Endpoint de Saque:

POST /api/pixout

Parâmetros:

{ "token": "seu_token", "secret": "seu_secret", "amount": 50.00, "pixKey": "11999999999", "pixKeyType": "phone", "baasPostbackUrl": "web" }

Resposta:

{ "status": "success", "data": { "transaction_id": "uuid-da-transacao", "amount": 50.00, "status": "PROCESSING" } }

🔄 Callbacks

A PrimePay7 enviará notificações para os seguintes endpoints:

🎯 Callback Unificado (Recomendado):

POST /api/primepay7/callback
✨ Novo! Este endpoint detecta automaticamente se é um depósito ou saque baseado no conteúdo da requisição. Configure apenas este URL no painel da PrimePay7 para simplificar a configuração.

Callbacks Específicos (Opcionais):

POST /api/primepay7/callback/deposit
POST /api/primepay7/callback/withdraw

Webhook Geral:

POST /api/primepay7/webhook
💡 Recomendação: Use apenas o callback unificado /api/primepay7/callback para simplificar a configuração. O sistema detectará automaticamente o tipo de transação.

🤖 Detecção Automática de Transações

O callback unificado detecta automaticamente o tipo de transação analisando:

Campos Analisados:

  • transaction_type: "deposit" ou "withdraw"
  • type: Tipo da transação
  • event: Tipo do evento (payment.received, withdraw.completed, etc.)
  • status: Status da transação
  • direction/flow: Direção da transação ("in" = depósito, "out" = saque)
  • amount: Valor positivo = depósito, negativo = saque
  • description: Descrição contendo palavras-chave
  • category: Categoria da transação
  • operation: Tipo de operação
  • transaction_id: Consulta no banco de dados

Exemplos de Detecção:

// Depósito detectado por: { "transaction_type": "deposit", "status": "PAID", "amount": 100.00 } // Saque detectado por: { "event": "withdraw.completed", "status": "COMPLETED", "amount": -50.00 }

📊 Status das Transações

Os status suportados pela PrimePay7 são:

  • PAID/APPROVED/COMPLETED: Transação aprovada
  • FAILED/REJECTED/CANCELLED: Transação rejeitada
  • PENDING/PROCESSING: Transação em processamento

🔐 Autenticação

A PrimePay7 utiliza autenticação OAuth2 com Client Credentials:

1. Enviar client_id e client_secret para /auth/token 2. Receber access_token 3. Usar access_token no header Authorization: Bearer {token}
