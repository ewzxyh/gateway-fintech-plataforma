🧪 Teste XDPag - Gateway

📋 Informações da Adquirente

Nome: XDPag

Referência: xdpag

URL Base: https://api.xdpag.com

Status: Integração completa com Cash In e Cash Out

🔧 Configuração

Para configurar a XDPag, acesse: Admin → Ajustes → Adquirentes

Campos necessários:

  • Client ID: ID do cliente fornecido pela XDPag
  • Client Secret: Chave secreta do cliente
  • URL: URL da API (https://api.xdpag.com)
  • Webhook Secret: Chave secreta para validação dos webhooks
  • Taxa PIX Cash In: Taxa para depósitos PIX
  • Taxa PIX Cash Out: Taxa para saques PIX

🌐 Webhooks

Os webhooks da XDPag estão configurados nos seguintes endpoints:

  • Cash In (Depósitos): POST /api/xdpag/callback/deposit
  • Cash Out (Saques): POST /api/xdpag/callback/withdraw
  • Teste: POST /api/xdpag/test

📊 Funcionalidades Implementadas

  • ✅ Model XDPag: Gerenciamento de configurações
  • ✅ Service XDPagService: Integração com API
  • ✅ Controller XDPagController: Processamento de webhooks
  • ✅ Trait XDPagTrait: Lógica de negócio para saques
  • ✅ Webhooks: Cash In e Cash Out
  • ✅ Controle de Taxas: Configurável via admin
  • ✅ Interface Admin: Configuração via painel
  • ✅ Logs: Rastreamento completo de operações
  • ✅ Validação: Middleware de segurança
  • ✅ Callbacks: Notificações para sistemas externos
